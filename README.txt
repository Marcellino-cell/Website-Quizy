EDUGEN AI — WEBSITE RANGKUMAN MATERI INTERAKTIF

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder website-rangkuman-ai.
3. Klik dua kali file index.html (Chrome, Edge, atau Firefox).
4. Pastikan file index.html, style.css, dan script.js tetap berada dalam satu folder.

Fitur:
- 6 modul rangkuman tentang Generative AI untuk pengembangan media pembelajaran.
- Pencarian modul secara langsung.
- Dialog materi, tombol sebelumnya/selanjutnya, dan status selesai.
- Progres belajar otomatis tersimpan di localStorage browser.
- 10 soal kuis interaktif dengan kunci dan pembahasan setelah menjawab.
- Tema gelap/terang, menu mobile, responsif.
- Rincian 8 komponen tugas akhir.

Struktur:
index.html  = Struktur dan isi halaman utama
style.css   = Desain tampilan dan responsivitas
script.js   = Materi, kuis, pencarian, progres, navigasi, tema

Penting:
- Koneksi internet hanya diperlukan untuk mengunduh font Google, tetapi halaman dan fiturnya tetap dapat digunakan tanpa font tersebut.
- Progres tersimpan hanya di browser/perangkat yang sama.
- Sebelum dikumpulkan, sesuaikan informasi pemilik karya dan periksa kembali materi menurut arahan pengajar.
